# Guard worst-case directional exposure

The Directional Guardrail evaluates an Exposure Interval across wallet holdings, venue balances, and every resting order independently for each Outcome Market. This accounts for partial and future fills that a balance-only check misses; Mixed and Unknown Positions fail closed for new Directional Intents while cancellation, fund settlement, Pair Redemption, and exit recovery remain available. The normal UI never knowingly submits an order that would match the same wallet's resting order: it routes the user through cancellation, fund settlement, and direct Pair Redemption instead. Any solvent on-chain self-cross caused by a race or adversarial call is classified as an Internal Unwind, not external price discovery or a realized sale.
