# Denominate collateral liability in atoms

Collateral Liability is stored in outcome-token atoms, with one outcome-token atom corresponding to one USDC atom because both assets use six decimals. Solvency compares raw vault atoms against this accounted liability, tolerating unsolicited surplus while avoiding the ambiguity and rounding errors of counting whole pairs and multiplying later. Because a classic SPL token-account owner can burn held tokens without invoking Meridian, anyone may reconcile liability monotonically downward from canonical mint supplies: while `outcome == Unset` it is `max(yes_supply_atoms, no_supply_atoms)`, and once `outcome != Unset` it is the winning mint's supply. `settle_market` sets the winner, reconciles with the explicit post-Settlement phase, and only then marks the Market Settled in the same atomic transaction. A holder burn is unsupported voluntary forfeiture, never releases collateral, and leaves any newly unencumbered USDC as ownerless V1 Collateral Surplus.
