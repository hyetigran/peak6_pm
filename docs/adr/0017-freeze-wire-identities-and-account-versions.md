# Freeze wire identities and account versions

Wire IDs are permanent explicit discriminants: `TickerId` uses Invalid 0, AAPL 1, AMZN 2, GOOGL 3, META 4, MSFT 5, NVDA 6, and TSLA 7; `MarketState` uses Uninitialized 0, Created 1, Active 2, Settled 3, and Abandoned 4; `Outcome` uses Unset 0, Yes 1, and No 2; `SettlementRecordState` uses Pending 0, FinalOracle 1, and FinalManual 2. All other values are reserved and declaration order is never serialized implicitly. Config, Outcome Market, Settlement Transport Version (`FeedVersion`), and SettlementRecord accounts use an explicit `u8` schema version and `[u8; 64]` reserved padding. IDs are never reused, fixed-field hashes exclude account discriminators and padding, and golden vectors protect every canonical identity and commitment. User-visible Market Phase is a projection rather than the serialized `MarketState` enum.
