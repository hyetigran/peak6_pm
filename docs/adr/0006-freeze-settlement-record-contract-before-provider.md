# Freeze the settlement-record contract before selecting a provider

Meridian defines its required Settlement Record before choosing a vendor: an immutable record for the exact ticker and Trading Day must supply the unadjusted Official Close and its observation time, with correction and corporate-action behavior understood. The provider-independent contract uses stable fixed-width fields and domain-separated canonical hashes, exact sample agreement in V1, delivery-account freshness evaluated at submission without an acceptance expiry, explicit final/unadjusted flags, a state-specific FinalOracle/FinalManual population table, and the enforced temporal order `close <= official observation <= exchange publication <= provider observation <= submission Clock`. Provider selection follows a go/no-go calibration against this contract so vendor convenience cannot silently weaken settlement correctness.
